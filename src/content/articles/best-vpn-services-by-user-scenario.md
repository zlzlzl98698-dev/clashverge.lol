## 一、四大典型用户画像的精准严选方案

### 画像 1：AI 程序员与重度生产力工作者（Cursor / Claude / ChatGPT / GitHub）
- **核心痛点**：讨厌 Cloudflare 频繁弹验证码、要求 Claude 账号稳定不封号、终端 `git clone` 与 Docker 拉取要快。
- **严选组合**：
  - **方案 A（全能老牌）**：**[光速云 极速版（¥25/月，168GB）](/brands/guangsuyun/)** + [Clash Verge Rev](/clash/verge/)（开启 TUN 模式，将 AI 域名分流至美/日/英节点，日常开发走 22ms 香港节点）。
  - **方案 B（AI 针对型）**：**[速界（¥25/月，150GB）](/brands/sujie/)**（25元档唯一专门强调三大 AI 工具落地的 IEPL 品牌）或 **[一翻云（¥20/月，150GB）](/brands/yifan/)**（IEPL + 原生住宅 IP + Hysteria 2 协议）。

### 画像 2：Apple TV 家庭影院控与软路由多设备玩家
- **核心痛点**：家里手机、iPad、电脑、Apple TV 4K 甚至 Switch 共七八台设备同时在线，且必须在软路由（OpenClash/PassWall2）或 tvOS 上导入订阅。
- **严选组合**：
  - **首选**：**[星岛梦（¥25/月 150GB 或 ¥50/月 300GB）](/brands/xingdaomeng/)** —— 2020 年老牌 IEPL，Trojan 协议，**明确 1 倍流量且不限设备数**，节点还包含韩国与东南亚。
  - **平价之选**：**[唯兔云（¥19.9/月 150GB）](/brands/weitu/)** —— IPLC 专线 + Trojan 协议，同样 **1 倍流量、不限速、不限设备连接**，实测香港 500Mbps / 新加坡 414Mbps。

### 画像 3：高校研究生与学术科研党（Google Scholar / 文献下载 / 预算敏感）
- **核心痛点**：主要在校园网或宿舍使用，查英文文献、下 PDF、用网页版 AI 润色论文，每月流量消耗在 30–60GB 左右，希望年均支出控制在百元以内。

## 二、入手新服务后的「首月 7 项硬核验真清单」

当你花 ¥18–¥25 买下任何一家机场的第一个月套餐后，请在首月内按以下 7 项清单给它做一次全面体检，合格后再考虑季付或年付：

| 检验序号 | 验真项目 | 合格标准参考值 | 不合格表现与应对 |
| :---: | :--- | :--- | :--- |
| **01** | **晚高峰（21:00）香港/新加坡 Speedtest** | 下行速率保持在闲时的 **70% 以上**（≥200Mbps），抖动 `<15ms` | 若晚高峰暴跌至 `<10Mbps`，说明母鸡严重超售，到期即换 |
| **02** | **YouTube 4K 60fps 详细统计信息** | 右键开启“详细统计信息”，Connection Speed `≥80,000 Kbps` 且 `0 dropped frames` | 频繁缓冲掉帧说明 UDP/QUIC 或 TCP 窗口受限 |
| **03** | **DNS 泄漏自检（ipleak.net）** | DNS 服务器列表中**不出现中国大陆运营商 IP** | 若出现国内 DNS，需在 Clash 中开启 Fake-IP 模式 |
| **04** | **AI 三大件可用性（GPT/Claude/Gemini）** | 切换美/日/新节点后无需频繁点验证码即可正常对话 | 若全节点均被封锁，说明落地 IP 池纯净度差 |
| **05** | **Netflix 非自制剧检测** | 搜索《绝命毒师》（Breaking Bad）能正常显示并播放 | 若搜不到《绝命毒师》，说明仅解锁自制剧（Originals Only） |
| **06** | **节点倍率扣费核对** | 下载一个 1GB 测试文件后，后台流量账单准确扣除约 1GB | 若扣除 2GB–5GB，说明暗藏高倍率节点 |
| **07** | **客服工单响应速度** | 工作日提问在 2–12 小时内获得有效人工或智能解答 | 若工单超过 3 天石沉大海，切勿续费长周期套餐 |
