## 一、零基础新手的“两条极速通关路线”（10分钟搞定）

很多新手一上来就被网上的进阶教程吓跑了。其实在 2026 年，你根本不需要先去考一个网络工程师证书才能上网。请根据你的性格在下面两条路线中任选一条：

### 路线 A：极致省事路线（3分钟搞定，0配置门槛）
**适合人群**：看到英文界面或代码就头疼、只想在电脑和手机上装个 App 点一下就能连的用户。
1. **选品牌**：
   - 想要 **2020 年老牌双专线 + 以后还能升级用 Clash**：选 **[光速云](/brands/guangsuyun/)**（优惠码 `AMM`，轻量版 ¥99/年 或 极速版 ¥25/月）。
   - 想要 **60+ 节点小白一键登录 + 支持通用订阅**：选 **[梯子云](/brands/tiziyun/)**（优惠码 `tiziyun`，年付约 ¥7.4/月）。
   - 想要 **纯专属客户端、学生党超低总价**：选 **[飞猫云](/brands/feimao/)**（优惠码 `flycat888`，学生版 ¥84/年）或 **[无忧链接](/brands/wuyou/)**（优惠码 `wuyou666`，MINI版 ¥79/年）。
2. **怎么用**：注册并购买入门套餐后，直接在机场后台下载它们自带的 **官方专属客户端**，输入你的注册账号和密码，点击连接按钮即可！

### 路线 B：标准进阶路线（10分钟搞定，解锁最强分流体验）
**适合人群**：希望电脑、手机、平板精细分流（看视频走香港22ms、用ChatGPT走美国），喜欢干净开源软件的用户。
1. **选品牌**：在 **[光速云](/brands/guangsuyun/)**（¥25/月 168GB）、**[一翻云](/brands/yifan/)**（¥20/月 150GB）、**[唯兔云](/brands/weitu/)**（¥19.9/月 150GB）、**[微风网络](/brands/weifeng/)**（¥27/月 200GB）或 **[暮光加速](/brands/muguang/)**（¥20/月 120GB）中任选一家。
2. **装软件**：按照《[Clash Verge Rev 官方下载教程](/guides/clash-verge-rev-download-and-install-guide/)》安装客户端。
3. **导订阅**：按照《[Clash Verge 订阅导入教程](/guides/clash-verge-subscription-import-and-conversion/)》把订阅链接粘贴进去，打开「规则模式（Rule）」与「系统代理」，大功告成！

## 三、新手必存：20 个机场与 Clash 高频术语“大白话词典”

以后看评测文章遇到不懂的词，直接查这张表：

| 序号 | 专业术语 | 一句话大白话解释 |
| :---: | :--- | :--- |
| **01** | **机场 (Airport)** | 提供大量海外代理服务器节点并通过订阅链接打包卖给用户的服务商（因为早期软件图标是一架纸飞机而得名）。 |
| **02** | **订阅链接 (Subscription)** | 一个包含你个人专属密码的网址，把它贴进 Clash 软件里，软件就能自动下载并更新这家机场的所有节点和分流规则。 |
| **03** | **直连线路 (Direct)** | 你的电脑直接连海外服务器，中间必经公网防火墙（GFW），一到晚上高峰期就容易卡成幻灯片。 |
| **04** | **中转线路 (Relay)** | 先连国内一台云服务器，再由它转发到海外，比直连稳，但过境段依然走公网。 |
| **05** | **IPLC / IEPL 专线** | **内网物理专线**（如深港专线），数据包从国内机房走独立内部通道直达香港，不经过公网防火墙，晚高峰最稳、延迟最低。 |
| **06** | **BGP 入口** | 国内支持电信、联通、移动三网高速同时接入的机房入口，不管你家里是哪家宽带都能就近低延迟入网。 |
| **07** | **VLESS / Trojan / Hy2** | 三种现代化的加密传输协议（类似快递加密打包标准），必须用新版客户端（如 Clash Verge Rev）才能识别连接。 |
| **08** | **Mihomo (Clash.Meta)** | 目前全网唯一持续更新的开源 Clash 核心大脑，支持 VLESS 和 Hysteria 2 等全部新协议。 |
| **09** | **Sing-box** | 另一款极其轻快省电的新一代代理核心，Hiddify 和 Karing 客户端就是用它做的。 |
| **10** | **规则模式 (Rule)** | **日常必开模式**：自动识别网址，访问国内淘宝/微信直接走你家宽带，访问 Google/YouTube 才走海外节点。 |
| **11** | **全局模式 (Global)** | 不管三七二十一，把国内国外所有流量全塞进海外节点，会导致国内网速变慢且狂掉流量，平时别开。 |
| **12** | **系统代理 (System Proxy)** | 让浏览器和常规桌面软件走代理的总开关。 |
| **13** | **TUN 模式 (虚拟网卡)** | 在电脑里创建一个虚拟网卡，把不听“系统代理”话的终端命令行（Git）和外服游戏也全部抓进代理分流。 |
| **14** | **节点倍率 (Multiplier)** | 流量扣费系数。`1倍(×1)` 就是用 1GB 扣 1GB；如果标着 `3倍(×3)`，用 1GB 会扣掉你套餐里 3GB 流量。 |
| **15** | **按月重置 vs 不限时** | 年付套餐每月账单日清零重新给满流量；一次性不限时套餐则是总流量用完为止，没有过期时间。 |
| **16** | **原生 IP (Native IP)** | 注册国家和机房所在地完全一致的纯正本地 IP，看 Netflix 当地非自制剧和动画疯必备。 |
| **17** | **IP 送中** | 海外节点的 IP 因为被太多开了定位的中国大陆用户共用，被 Google 误判为中国大陆地区，导致 YouTube 会员功能受限。 |
| **18** | **Fake-IP** | Mihomo 内核的一种防 DNS 污染黑科技，先给浏览器秒回一个 `198.18.x.x` 假 IP 建立连接，再由海外服务器安全解析真实网址。 |
| **19** | **Merge (本地覆写)** | 在不破坏机场原有订阅的前提下，在本地安全追加你自己的自定义分流规则。 |
| **20** | **跑路 (Exit Scam)** | 机场老板停止维护服务器并关站失联。防范跑路最有效的方法就是“先买月付实测，绝不贪便宜买三年付”。 |
